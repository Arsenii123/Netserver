# Зміни у проєкті

- **Сервер**  
  - Додали поле `Name` у `ConnectRequest`, щоб клієнт міг передати своє ім’я.  
  - Реалізували метод `GetClientName`, який бере ім’я з таблиці `clients` за `clientId`.  
  - У `AddMessage` тепер використовується ім’я (`name`), а не `clientId`, тому у базі та логах видно `[brooo]: текст`.  
  - Клас `ChatMessage` має властивість `From`, яка серіалізується у JSON як `"from":"ім’я"`.  

- **База даних**  
  - Таблиця `clients`: зберігає `id`, `name`, `connectedAt`.  
  - Таблиця `messages`: зберігає `sender` (тепер ім’я), `text`, `isSystem`, `created_at`.  
  - Переконались, що типи колонок — `text` для `id`, `name`, `sender`.  

- **Клієнт**  
  - У `Connect` відправляється JSON з полем `name`.  
  - У `PollLoop` клієнт читає поле `from` із JSON‑відповіді сервера.  
  - У `PrintMessage` тепер показується `[ім’я]: текст`, а не `[unknown]`.  
  - Додали можливість тимчасово вивести «сирий» JSON для перевірки (`Console.WriteLine(json)`).

# База даних

У проєкті використовується **PostgreSQL**. Вона зберігає інформацію про клієнтів і їхні повідомлення.  

## Таблиця `clients`
- **id (text)** — унікальний ідентифікатор клієнта (GUID).  
- **name (text)** — ім’я, яке користувач вводить при підключенні.  
- **connectedAt (timestamp)** — час, коли клієнт приєднався до чату.  

📌 Ця таблиця потрібна, щоб сервер знав, яке ім’я відповідає якому `clientId`.  

## Таблиця `messages`
- **id (serial)** — унікальний номер повідомлення.  
- **sender (text)** — ім’я відправника (береться з таблиці `clients`).  
- **text (text)** — сам текст повідомлення.  
- **isSystem (boolean)** — позначка, чи це системне повідомлення (наприклад, «користувач приєднався»).  
- **created_at (timestamp)** — час, коли повідомлення було створене.  

📌 Тут зберігаються всі слова, які користувачі пишуть у чаті.  

## Як це працює разом
1. Коли клієнт підключається через `/connect`, його ім’я записується у `clients`.  
2. Коли він відправляє повідомлення через `/send`, сервер дивиться у `clients`, знаходить ім’я і записує його у `messages.sender`.  
3. При запиті `/poll` сервер віддає список повідомлень з іменами, щоб клієнт бачив у терміналі `[ім’я]: текст`.  

---

Таким чином, база даних — це «пам’ять» чату: одна таблиця пам’ятає **хто ти**, інша — **що ти сказав**.
